Morse code is a method used to encode text characters as sequences of dots(.) and dashes (-). Each letter, numeral or punctuation is represented by a unique combination of these two symbols. Morse code was widely used in telecommunication before the advent of modern communication technologies. 

Morse code was developed in the early 180 and 1840 as a means of long distance communication via telegraph. The first message sent using morse code was transmitted in 1844, which read, “what hath God wrought?” it became essential for maritime communication and was used extensively during wartime and in aviation.

Morse code operates by assigning a unique sequence of dots and dashes to each letter of the alphabet and numbers.
